# Coconut UI React - Repository Setup Implementation Plan

## Overview

Setting up a React UI component library (`@coconut-ui/react`) with TypeScript, Tailwind CSS styling, Storybook for component previews, and NPM publishing infrastructure.

**Organizations:**

- **Development/Testing:** `@coconut-beta` (for development and testing)
- **Production:** `@coconut-ui` (for production-ready releases)

---

## User Review Required

> [!IMPORTANT] > **NPM Organization Access**: Ensure you are logged into NPM with access to both `@coconut-beta` and `@coconut-ui` organizations before publishing.

> [!WARNING]  
> **Tailwind CSS Version**: This plan uses Tailwind CSS v4. If you prefer v3, please let me know before execution.

> [!IMPORTANT]  
> **Package Scope Decision**: Confirm that component imports should be structured as:
>
> - `import { Button } from '@coconut-ui/react'` (main export)
> - `import { Button } from '@coconut-ui/react/button'` (path-based import)

## Verification Plan

### Automated Tests

1. **Unit Tests (Vitest + React Testing Library)**

   ```bash
   npm run test
   ```

   - Component render tests
   - Props and variants testing
   - Accessibility testing with jest-axe

2. **Type Checking**

   ```bash
   npm run typecheck
   ```

   - Ensure all TypeScript types are valid

3. **Linting**

   ```bash
   npm run lint
   ```

   - ESLint validation for code quality

4. **Build Verification**
   ```bash
   npm run build
   ```
   - Successful bundle generation
   - Declaration files generated correctly

### Manual Verification

1. **Storybook Preview**

   ```bash
   npm run storybook
   ```

   - Verify all components render correctly
   - Test interactive controls
   - Check responsive behavior

2. **NPM Pack Test (Local Testing)**

   ```bash
   npm pack
   ```

   - Verify package contents
   - Test installation in a separate project

3. **Development Publish Test**
   ```bash
   npm publish --access public
   ```
   - Publish to `@coconut-beta/react`
   - Install in a test project to verify
